# Zoodlego

Official website for Zoodlego — Independent Mobile Game Studio.

Built with Next.js 16 (App Router), Tailwind CSS v4, Motion, and TypeScript.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

## Production Build

```bash
npm run build
```

Exports static output to `out/` for deployment.
